# Predicting Earthquakes Using 200 Years of Global Major Earthquakes

*200 Years of Global Major Earthquakes (1826–2026)*
- https://www.kaggle.com/datasets/dhrubangtalukdar/200-years-of-global-major-earthquakes-18262026

## Setup

### Conda environment

Create the environment once, then activate it when working on the project:

```sh
conda env create -f environment.yml
conda activate quake-ml
```

## Running notebooks

1) Generate the processed dataset:

```sh
python src/data_prep.py
```

2) Start Jupyter from the repo root and open the notebook you want:

```sh
jupyter notebook
```
